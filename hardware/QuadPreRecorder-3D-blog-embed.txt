HOW TO PUT THE 3D MODELS IN A BLOG POST ON ILLICITAPOTHECARY.COM
=================================================================

Squarespace does not host .html files itself, so it is a two step process:
put the file at a URL, then embed that URL in the post.

STEP 1: Host the two HTML files somewhere that serves web pages.
  The easiest free option is GitHub Pages (you already use GitHub):
    1. Make a new public repository, for example "qpr-3d".
    2. Upload QuadPreRecorder-enclosure-3D-labeled.html and
       QuadPreRecorder-1590F-concept-3D.html to it (drag and drop on github.com).
    3. In the repo: Settings > Pages > Source: "main" branch > Save.
    4. After a minute the files are live at:
       https://YOURUSERNAME.github.io/qpr-3d/QuadPreRecorder-enclosure-3D-labeled.html
       https://YOURUSERNAME.github.io/qpr-3d/QuadPreRecorder-1590F-concept-3D.html

STEP 2: In the Squarespace blog post editor, add a CODE block
  (Add block > Code, leave it on HTML) and paste this in, with your real URL:

<iframe src="https://YOURUSERNAME.github.io/qpr-3d/QuadPreRecorder-enclosure-3D-labeled.html"
        width="100%" height="640"
        style="border:0;border-radius:10px;overflow:hidden"
        loading="lazy" title="QuadPreRecorder 3D model"></iframe>

  And for the 1590F concept, the same thing with the other file name:

<iframe src="https://YOURUSERNAME.github.io/qpr-3d/QuadPreRecorder-1590F-concept-3D.html"
        width="100%" height="640"
        style="border:0;border-radius:10px;overflow:hidden"
        loading="lazy" title="QuadPreRecorder 1590F concept 3D model"></iframe>

Notes:
- Code blocks work on your Business plan.
- Readers drag inside the frame to rotate, scroll to zoom, and get the
  view buttons and label toggle, exactly like the local file.
- height="640" is a good desktop size; make it 480 if you want it shorter.
- If you ever update a model, just replace the file in the GitHub repo and
  every post embedding it updates automatically.
