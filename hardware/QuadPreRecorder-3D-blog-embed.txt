PUTTING THE 3D MODEL IN A BLOG POST ON ILLICITAPOTHECARY.COM
=============================================================

Your quadpreandrecorder repo is PRIVATE, and GitHub Pages on a free plan only
works on public repos (and you would not want the whole hardware design public
anyway). So the play is: one tiny PUBLIC repo that holds only the viewer file.

PART 1: Host the file (about 3 minutes, once)
  1. Go to github.com, click the + in the top right, "New repository".
  2. Name it: qpr-3d   Visibility: Public.   Click "Create repository".
  3. On the new empty repo page click "uploading an existing file".
  4. Drag in QuadPreRecorder-enclosure-3D-labeled.html from
     Documents\quadpreandrecorder\hardware (add the 1590F concept file too if
     you ever want it in a post). Click "Commit changes".
  5. In the repo: Settings > Pages (left sidebar) > under "Branch" pick
     "main" and "/ (root)" > Save.
  6. Wait about a minute, refresh the Pages screen, and it shows your live
     URL. The model is then at:
     https://jdg511.github.io/qpr-3d/QuadPreRecorder-enclosure-3D-labeled.html
     Open that in a browser to confirm it spins.

PART 2: Embed it in the Squarespace post (per post)
  1. Edit the blog post, click an insert point, and add a CODE block
     (Add block > Code). Leave its type on HTML, "Display Source" OFF.
  2. Paste this in:

<iframe src="https://jdg511.github.io/qpr-3d/QuadPreRecorder-enclosure-3D-labeled.html"
        width="100%" height="640"
        style="border:0;border-radius:10px;overflow:hidden"
        loading="lazy" title="QuadPreRecorder 3D model"></iframe>

  3. Save the post. Code blocks work on your Business plan. Note: Squarespace
     only renders the iframe on the real published page, not always inside
     the editor preview, so check the live post.

Updating the model later: replace the file in the qpr-3d repo (upload with the
same name, commit) and every post that embeds it updates by itself.

Height 640 is a good desktop size; 480 if you want it shorter. Readers drag to
rotate, scroll to zoom, and get the view buttons and label toggle.
