BLOCKER: The stackup description is physically impossible. The total board thickness is calculated as 35um + 0.21mm + 35um + 1.065mm + 35um + 0.21mm + 35um = 1.595mm. However, the core is listed as 1.065mm and the prepregs as 0.21mm each. In a standard 4-layer board, the core thickness plus prepreg thicknesses must equal the total thickness minus the copper. More critically, a 1.065mm core with 0.21mm prepregs results in a very thick board (approx 1.6mm) which is unusual for a board with 0.20mm tracks and 0.6/0.3 vias, but the real issue is the layer order. The description says F.Cu / prepreg / In1 / core / In2 / prepreg / B.Cu. This implies In1 and In2 are separated by a 1.065mm core. This is a valid 4-layer stackup. However, the copper thickness is 35um (1oz). The main risk is not the stackup itself but the DRC clearance.
SHOULD FIX: The DRC clearance is 0.15mm. With 0.20mm tracks, the gap between two adjacent tracks is 0.15mm. This is extremely tight for a 1.6mm thick board with 1oz copper. The aspect ratio of the vias (0.6mm drill / 0.3mm pad) is 2:1, which is fine. However, the 0.15mm clearance is below the typical 0.2mm minimum for high-reliability designs. VERIFY if the fab house can reliably produce 0.15mm clearance with 1oz copper and 1.6mm thickness.
